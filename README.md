# How Many Tabs Do You Have Open?

**137.**

A real, lived-in tab-hoarder count: far above the 5–30 most people have, yet believable as an honest tally — odd and specific, not a round shock number. It hints at a life of never-closed research rabbit holes.

Run `python3 main.py` (Python 3.13, stdlib only, no network). It writes exactly `137` — no newline, no other text — to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (defaults to `out`).
